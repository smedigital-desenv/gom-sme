# GOM/SME — v48 Oculta data global da Empresa

Oculta o campo `Data padrão dos cards` na tela Empresa > Execução diária.

A regra dos cards continua a mesma:

- cada card abre com a data de hoje pré-setada;
- a data pré-setada não salva sozinha;
- somente cards com mudança de equipe e/ou data manual entram no salvamento.

No código, o bloco para voltar a exibir o campo ficou comentado em `js/empresa.js`.
